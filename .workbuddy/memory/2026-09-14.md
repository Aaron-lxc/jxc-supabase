## 父菜单点击修复（fix(app)，commit a7b0610，已 push main）
- 问题：① 点击「活动管理」报「未知页面: activity」；② 点击「合伙人管理」只展开子菜单，无法进入原合伙人管理页面（资源合伙人/区域合伙人/区域考核）。
- 根因：`goParent(m)` 未区分父菜单自身是否有对应页面；简单禁止所有父菜单加载页面会丢失「合伙人管理」这类父级即页面的功能。
- 修复：父菜单含 children 时，先强制展开子菜单；若 `PAGE_FILES[m.key]` 存在（如 partners）则同时 `go(m.key)` 加载页面，否则仅展开（如 activity）。叶子菜单仍正常加载。
- 校验：`node --check js/app.js` + `validate-templates.cjs` 通过（31 模板 0 失败、20 断言 0 失败）。
- 部署：单次 push，等 Pages 绿勾后刷新测试。
